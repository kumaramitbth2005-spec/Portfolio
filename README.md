# Portfolio Website

A modern, responsive personal portfolio website built with HTML, CSS, JavaScript, and Bootstrap.

## Features
- **Robotic Theme**: High-tech, futuristic design with glassmorphism and neon accents.
- **Interactive Globe**: 3D animated globe using Three.js.
- **Responsive Design**: Fully compatible with mobile, tablet, and desktop devices.
- **Typing Animations**: Dynamic text effects for a professional look.
- **Project Showcase**: Highlighted projects with images and links.
- **Skill Cards**: Interactive cards with detailed notes on technologies.
- **Certificate Gallery**: Interactive modal gallery for professional certifications.

## Technologies Used
- HTML5 & CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Three.js (for the 3D Globe)
- Google Fonts (Outfit)
- Bootstrap Icons

## How to Run
Simply open `index.html` in any modern web browser.
